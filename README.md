# Práctica 1 — Primeros pasos con Git y GitHub - Javier

Este repositorio corresponde a la Práctica 1 de la asignatura, donde se aplican conceptos de control de versiones con Git, GitHub y SourceTree.

## Descripción
Repositorio de prueba diseñado para poner en práctica la creación de repositorios, gestión de ramas local y remotamente, y registro de commits mediante comandos y cliente gráfico.

## Ramas
* **main:** Rama principal que contiene la versión estable de la práctica y la documentación general.
* **desarrollo:** Rama secundaria utilizada para incluir nuevos recursos e imágenes antes de su integración final.
